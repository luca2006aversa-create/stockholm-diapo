# Stockholm — comment la ville s'est construite

Présentation interactive : l'évolution des formes urbaines de Stockholm, de l'an 800 à aujourd'hui.
Ouvrir `page/` (ou le lien GitHub Pages du dépôt). Défiler pour parcourir ; touche **P** pour le mode diaporama.

Sources et crédits : indiqués dans la page (diapo « Sources ») — OpenStreetMap, JRC Global Surface Water, ESA WorldCover,
FABDEM (CC BY-NC-SA 4.0, usage non commercial), GHSL, Wikimedia Commons (portrait de la statue de Birger Jarl : Ad Meskens, CC BY-SA 4.0), etc.
